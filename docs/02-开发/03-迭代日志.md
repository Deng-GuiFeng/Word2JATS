### R9 — 多代理审计新样例输出 + 据此修 11 类可泛化缺陷
用 5 个独立 Subagent(无 GPU,跑主模型)对照源 docx 逐模块审计新样例输出,只采纳**可泛化**发现。据此修复(每条都验证非过拟合、原 5 样例零回退):
1. **图表题注 re.I 误判**:`[A-Z(]` 因 re.I 也匹配小写→"Fig. 1 shows…"正文句被当题注且吃掉首字。改用 `(?i:…)` 局部标志,只让关键词大小写不敏感;新增 LABEL_STRIP 只剥标签不碰标题首字。
2. **交叉引用跳号错位(高)**:文献编号跳号(如缺[16])时,ref id 顺序编而 xref 按显示号拼→大面积指向错误文献。改为 ref id 取自显示编号 + label→id 映射;样例2 76个bibr xref 零错位。
3. **ORCID 人名X污染(高)**:normalize_orcid 对整段裸抽 [\dxX],人名 "Xiaoze" 的 X 混入→长度≠16丢弃。改为先正则定位 ORCID 记号;样例1/3/5 ORCID 正确(样例3 Li↔Tan 不再错配)。
4. **学术编辑多人**:"Editors: A and B"/"A, B" 并成一人且残留"s:"。改为剥前缀+按 and/&/;/, 拆;样例2/3/4 各2位正确。
5. **结构化摘要小标题**:补 Mechanism/Findings in Brief/Importance 等;样例2 摘要 2→4 节。
6. **Supplementary Fig/Table** 不再误链到正文同号图表。
7. **单位无关键词漏建(高)**:"Academician Workstation…"无机构词→漏 aff2。改为按作者上标编号兜底识别;样例4 aff1/2/3 齐。
8. **通讯标记(非上标*)**:"Kang1,2*  Zhao"的 * 落到下一作者段开头→丢失。改为归属上一作者;样例5 通讯 Kang/Zhao 正确。
9. **多位上标编号**:"12,3"(漏逗号)→只留 aff3。各位都对应已有单位时拆分;样例3 Hu/Zhou 得 aff1,2,3。
10. **共同贡献脚注**:忠实搬运 docx 原文,扩充措辞识别(joint first author 等)。
11. **前置区声明小节**:Funding/Conflict/Author Contributions 出现在作者信息页(非正文尾)时被丢弃→新增前置区声明扫描收入 back;样例3 补回三节。

### R12 — 把"一次性 LLM 调用"补成真正的 Agent 视觉闭环(质量保证核心)
此前的根本缺陷:虽已接入本地 VLM,但只是**一次性调用**(看图建表、重抽作者),**没有"测试→分析→修复→再测试"的迭代视觉核对闭环**——这才是质量托底的本体。本轮补上真正的闭环,并把作品定位从"规则草稿 + 一次性模型增强"纠正为"**LLM 驱动的 Agent 视觉闭环为核心、热启动草稿为加速器、`--llm off` 为向后兼容兜底**"。权威说明见 `../01-设计/02-智能循环架构.md`。

- **闭环长什么样**:渲染输入 Word 为页面图(人眼真值,只渲一次)→ VLM 逐页视觉清点(只清点一次,缓存)→ 每轮把视觉证据与我们产出的 XML 调和找差异 → 就地修复 → 再核对,直到无可修复 finding / 改不动 / 到轮数上限。视觉真值来源(渲染图 + VLM)独立于被测解析器,非循环论证。
- **新增 6 个 agent 模块**:`render.py`(docx→PDF(soffice)→PNG(pdftoppm),纯 CPU,内容哈希缓存)、`inspect.py`(VLM 逐页视觉普查,并发 + 按图片哈希缓存)、`outline.py`(确定性解析自产 XML → 计数 + 文本提纲)、`reconcile.py`(视觉⟷XML 调和:确定性计数差 + LLM 整体调和 → findings)、`repair.py`(修复路由)、`loop.py`(多轮编排,收敛即停)。`--agent` / `--agent-rounds` 接线进 `pipeline.convert`(调 `agent.loop.run_agent_loop`),`cli.py` 暴露开关。
- **关键修复(均为通用正确性,非过拟合)**:
  1. **漏表插入的 DTD 合规**:重建的 `<table-wrap>` 必须落在小节 prose 区(子 `<sec>` 之前),否则违反 JATS 内容模型 `(p|table-wrap|…)*, sec*` 致校验失败。优先插到题注段之后;若题注处于子 sec 之后(罕见)则安全回退到该 sec 的 prose 区。
  2. **同页多表的定向重建**:用视觉证据(标签 + 大致行列)生成定向提示,让 VLM 只转录目标那一张,避免串到相邻表;漏表重建的 VLM 调用先并发、树插入再串行,避免多表串行干等。
- **诚实边界**:可靠修复 = 重抽作者、看图重建漏表;其余(漏图/漏式/文献数差/标题层级)记为**已验证 finding** 进 trace 与透明报告,不静默乱改。
- **透明交付**:每次 `--agent` 落盘 `{article_id}.agent-trace.json`(一次普查 + 逐轮 findings/已修复/跳过原因/前后计数);新增 `scripts/eval_agent.py` 产出 `reports/agent/index.html`(渲染页 + 视觉普查 + 逐轮 findings 与修复 + 草稿/闭环/金标准计数对照 + DTD + 耗时)。
- **已验证**:`python -m word2jats convert <docx> --llm local --agent` 对样例2(8 张图片表)得表 **8/8**、DTD 通过,闭环核对确认匹配;新增 `tests/test_agent.py` 6 项确定性核心(渲染/XML 提纲/确定性调和/题注定位与插入/漏表识别/DTD 加载回归,不依赖 GPU/模型),**pytest 19→25 全过**(venv 与系统 python 双环境)。
