## 二、残余:可继续做的真改进

> 这些是查证后确认**能收窄**的口径差,非度量伪差;逐条看 `reports/eval/final/eval.txt`。

- [ ] **原生表头 `scope="col"`(当前最大可收项)**:冻结的结构参考对原生表列表头统一带 `scope="col"`
      (评测里 `表头scope 参考={'col': N} 输出={'': N}`,横跨 9 个样例、几十张表),我们现按设计发**裸 `<th>`**、
      不带 scope。二者都 DTD 合法、表结构与单元格文字完全一致,只差表头单元格的 `scope` 属性。给原生表列表头
      条件性补 `scope="col"` 是**低风险确定性对齐**,是眼下单项收益最大的一处。(注意别无条件加:数据行内的
      行表头 / 复杂表未必都该是 `col`,需按表头结构判定。)
- [ ] **参考文献最难体例**:会议录(如 "2015 37th Annual International Conference of the IEEE EMBC")、
      书籍章节、APA 体例等,确定性锚点(著录尾部 `年;卷(期):页`)对不齐,LLM 偶有字段边界摆动;按设计对不齐
      即整条落 `mixed-citation`(零风险)。可继续把跨样例反复出现的规整变体补进确定性切分,难例保持 LLM 兜底。
- [ ] **参考"合作组织作者"归类**:如 TCGA 的 "Cancer Genome Atlas Research Network" 该进 `collab` 还是当作者
      `surname`,金标准与我们判定偶有出入(样例3 的 `[1]/[2]/[6]`)。属**字段归类**差,不是丢字;可在组装器加
      "全大写 / 含 Network·Group·Consortium 等词的整体名→collab"的判定。
- [ ] **图片字节对账**:个别外部化图与 `figures.zip` 来源 md5 不匹配或缺文件(样例2),需对账图源、补齐来源映射。
- [ ] **`<aff>` 放置位置**:结构参考里 `<aff>` 是 `<article-meta>` 直属,我们仍放在 `<contrib-group>` 内
      (两者都 DTD 合法,现行评测单位类语义对齐 0 缺陷、不计放置位置)。如需与结构参考完全一致可迁移,低风险确定性改动。
- [ ] **B 档补全(可选、不计结构分)**:DOI / ORCID / 刊名全称经期刊表或 CrossRef 补全,防过拟合可开关。

## 三、度量伪差 / 金标准人工判断(不追,如实记录)

> 跨样例最大的几类缺陷,逐条查证后确认是**评测口径差异或金标准的人工/编辑取舍**,而非真错;硬追即过拟合。

- **制表符 / 复杂表的列数(表 value 类,S04 等)**:制表符表是用 Tab 对齐的伪表格,没有真实网格,列数、双层
      表头合并全靠人判断(把对齐填充并列、合并双层表头);复杂表同理。金标准是人工判定的列数,我们矩形归一保证
      不丢字、不丢表,但无法精确复刻人工取舍(评测里表现为 `表形状(tr,th,td)` 计数差,如 S04 某表参考 7 列、
      我方 3 列)。设"精确复刻列数"目标就是过拟合。**(大差处仍值得逐表扫一眼是否有列被欠切,但不设复刻目标。)**
- **公式 MathML 文本化展开 near-miss(公式类,主要样例3)**:评测把 MathML 展开成文本串按语义键比对,Unicode
      组合字符、下标次序、原子切分处有细微差异,报告标注接近度 **92–97%**;**数学内容一致**,属展开口径差。
      (display 公式已把平衡括号折成 `<mfenced open close>` 与金标准对齐,见 `03-迭代日志.md` R17;残余即上述展开差。)
- **面板号词元切分(交叉引用 / L1 忠实,S03 等)**:金标准把 "Fig. 2a" 的面板号 `2a` 当**一个词元**;我们为
      正确建交叉引用把面板字母拆出(`Fig 2` + panel `a`),于是 `2a` 这个合并词元不再整体出现、被 L1 记"丢词"。
      **字符都在、链接正确**,是词元边界的口径差,不是真丢字。
- **现代文献文章号 vs 页码(参考 field)**:现代期刊常用文章编号(如 `e0123456`)代替连续页码,二者都是数字串、
      著录位置也相近,确定性与 LLM 都难 100% 区分某个数字是 `fpage` 还是文章号;金标准的归类本身也带编辑判断。
- **S03 图表引用"编辑取舍不链接"(交叉引用 extra)**:金标准出于编辑取舍对某些图表提及**不建链接**,我们忠实
      按源识别并建链 → 被计"多标"。忠实于源不该判错,不追。
- **S04 单 "#" / 日期歧义(L1 忠实)**:S04 里孤立的 `#` 记号与日期字段语义歧义(编号标记?日期分隔?),金标准的
      取舍带人工判断;我们忠实保留原文、不强判,被计近似差。
