# 04 · 系统设计

## 核心思路：判断结构与取回内容分工

转换中最需要模型的是语义判断：一段文字属于什么章节，一条文献从哪里开始、有哪些字段。最不应该交给模型的是重新誊写整篇论文。word2jats 因此让模型给出结构判断与定位线索，再由程序从 Word 原稿取回对应内容。

这不是“让模型生成 XML，再检查一遍”的全文生成路线，也不是只凭 Word 样式名的模板转换。模型提供对多样稿件的理解能力；字符位置、对象关联和确定性组装则限制内容改写，并为检查提供依据。

## 一篇稿件如何转换

    Word → 源对象图 → 多路结构理解 → 原文定位与全局归并
         → 语义文档 → JATS 与媒体 → 自动检查 → 编辑核对与导出

源对象图是对原稿的有序记录。段落、表格、文字范围、图片与公式的每次出现都有地址，资源与出现位置分开管理。程序还读取有效格式、自动编号、脚注、文本框等 Word 事实。它为后续提供内容依据，不提前把每段强行判成论文语义。

结构理解分为文首、正文、参考文献边界、文献字段、正文引文及压平表格等任务。模型读到的是带地址的清单。图片只以对象记号出现，不把像素识别结果作为论文文字。

原文定位把模型摘抄映射回原稿的字符范围。精确匹配之外允许受控的引号、空白等归一化；仍存在多解时，结合上下文与源顺序消歧。找不到可靠位置就保留问题，不拿模型改写的字符串替换原文。各路判断还要归并，检查角色冲突和未被认领的内容。

语义文档表示“这里是标题、这里是一张表、这段引用指向哪条文献”。正文与文献等内容字段存原文位置；渲染器按位置取字并组装 JATS，媒体按原始字节外部化。结构不同于原稿的视觉排版，但内容取回有来源。

## 文首是明确的例外通道

文首作者、机构、通讯关系等元信息由模型直接生成局部 JATS，再经合法性约束、源外词检查和独立内容核对；摘要与关键词仍按原文位置取回。该通道有利于表达复杂的人名、机构与联系关系，但不具有正文源指针相同的构造性约束。

因此，项目不声称“模型从不生成任何文字”，也不把词级检查通过解释为姓名、地址和关系全部正确。文首剪除只移除检测到的源外词，保留有原稿依据的 ORCID 等标识；修改记录进入报告，作者信息仍是编辑重点核对对象。

## 参考文献与交叉引用

先用两个不同问法独立识别文献条目边界，分歧处再裁决；得到条目后逐条并行识别作者、题名、刊名、年份、卷期页等字段。每个字段必须定位回原稿。

结构化著录会去掉某些排版分隔符，因此程序逐段检查未输出的源内容：只有封闭清单内的标点和著录连接词才能作为格式转换处理。若缺了作者、年份或其他实义文字，则整条退回 mixed-citation 保留原文，并提示核对。取舍是宁可少拆几个字段，也不以完整 XML 外壳掩盖著录内容缺失。

正文数字制和作者—年份制引文与文末实体关联，图表提及也建立链接。自动编号从 Word 编号结构恢复，不把编号误当正文不存在。链接闭合检查能发现不存在的目标，但“目标存在”不等于语义上绝对链接正确，疑难引文需要人工查看。

## 表格、图片与公式

原生 Word 表格按单元格与合并关系生成 JATS 表格。用制表符或换行排出的表格由模型辅助恢复列结构；无法可靠拆列时保留文字并提示编辑整理原稿。仅用于排版、单行且最多一格有内容的内嵌小表可透明并入外层单元格，不将此能力推广为任意嵌套表支持。

OMML 公式通过 XSLT 转为 MathML，保留一次变换产生的全部节点。图像公式、旧 OLE 对象与原生公式区别处理，不凭图猜数学表达式。图片不重编码，下载保留原始字节；预览格式转换与交付文件分离。

## 并行顺序为什么重要

文献切条、正文理解和引文识别可同时开展。字段提取只需等待文献边界，不必等正文；压平表格处理只需正文归并结果，不必等所有文献字段。

    文首判断 ─────────────────────────────┐
    文献切条 A/B → 分歧裁决 → 逐条字段提取 ─┤
    正文判断 ───────────→ 归并 → 表格处理 ─┼→ 装配与检查
    引文识别 ─────────────────────────────┘

实际归并还使用文献边界，上图仅突出主要依赖。每篇内部模型请求有并发上限；优化减少无依赖的等待，不承诺长文与短文同样快。全新转换与缓存重放分别记录耗时，不能用批量总耗时除以篇数冒充单篇延迟。

## 自动检查与人工判断各管什么

自动检查包括 XML 良构、DTD、ID 唯一性、引用闭合、媒体格式与字节、无冗余文件、源文覆盖、输出来源、已支持的 Word 结构以及理解结果。另提供独立词级差异供核对。

源文覆盖回答“原稿内容去了哪里”，输出来源回答“输出内容从哪里来”。两者不同于只看 XML 是否能解析；但定位、规范化与语义判断仍有边界。通过检查的结果可进入校样复核，未通过的候选也保留，便于定位、修订原稿后重新转换。

网页支持题名、作者、单位、通讯信息、ORCID 与出版信息的受控修订。人工修改另存 XML 版本，重新检查格式和结构，并同步更新预览与下载；原自动文件保留，可恢复。正文、复杂表格与公式可在 Word 中修订后重新转换。字段范围及版本处理见 [Web 应用](08-Web应用.md)。
