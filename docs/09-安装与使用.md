# 09 · 安装与使用

## 环境

需要 Python 3.10 及以上。Qwen 配置主流程使用 qwen3.7-plus、文首使用 qwen3.8-max；DeepSeek 配置使用 deepseek-flash。本机通过云端接口调用模型，不需要 GPU。JATS DTD、期刊配置与公式转换样式表随源码提供。

在解压后的 JiangLab 目录执行：

    python -m venv .venv
    .venv/bin/python -m pip install -r requirements.txt

Windows 对应的解释器是 .venv\Scripts\python.exe。下文采用 Linux/macOS 命令。

复制 .env.example 为 .env，在本地填写 DASHSCOPE_API_KEY（Qwen）或 DEEPSEEK_API_KEY（DeepSeek）。凭据只用于服务端请求；配置其中一种即可使用对应模型，两个均配置时可以在网页切换。

## 网页使用

    .venv/bin/python -m webapp

浏览器打开 http://127.0.0.1:8000，选择已配置的模型；网页预选 DeepSeek Flash。上传样例数据/03/初始文件.docx，可填写期刊 JIN 和 DOI 10.31083/JIN49347。等转换完成后，浏览成品、核对提示，保存复核记录并下载。本次模型用量在结果页展开查看，也保存在下载包的转换用量.json 中。

勾选“重新识别全文”表示重新调用模型；不勾选时允许复用同一请求已有回答。两种模式耗时不同，页面会标明模型调用情况。运行中保持服务进程开启。

## 命令行转换

    PYTHONPATH=src .venv/bin/python -m word2jats convert \
      样例数据/03/初始文件.docx \
      --journal JIN --doi 10.31083/JIN49347 --llm deepseek --model deepseek-flash -o output/

上述命令与随包输出采用相同模型配置。使用 Qwen 组合时，将模型参数替换为 `--llm dashscope`，不指定 `--model`，由程序分别使用主流程和文首的预设模型。可用 --publication-year 显式提供出版工作流已确认的年份。参数全表：

    PYTHONPATH=src .venv/bin/python -m word2jats convert --help

每次先写候选和检查报告。自动检查通过后发布到输出目录；未通过的候选位于 failed 子目录，仍包含可查看的 XML、媒体及报告。--no-validate 只用于诊断，不能将跳过检查的结果标作正式通过。

## 查看随包结果

输出样例/ 中提供 Qwen 组合配置生成的 14 例 XML、配套媒体、图片压缩包、检查摘要与离线预览。打开各例的预览.html 即可阅读已生成结果，不需要 API。离线预览是冻结结果展示，不是重新调用模型。

样例数据/ 中同时提供原稿、结构对照材料和图片包，便于检查论文内容与出版结构，详见 [数据说明](03-数据与结构参考.md)。

## 验证与重放

测试依赖单独安装：

    .venv/bin/python -m pip install -r requirements-dev.txt
    .venv/bin/python -m pytest -q

全新运行 14 例并分别计时：

    PYTHONPATH=src .venv/bin/python -m scripts.finals_run \
      --tag my-run --provider dashscope --workers 1

使用 DeepSeek 时改为 `--provider deepseek --model deepseek-flash`。标签须为未使用过的名称。每篇调用云模型，会产生费用。结果写入 reports/outputs/my-run，模型响应写入 reports/_llm_cache/my-run。逐篇计量保存实际返回的 usage；通过 `python -m scripts.proposal_metrics --tag my-run` 生成全文分项指标。

核对实际文件中的文献、公式、ORCID、图片字节与引用：

    PYTHONPATH=src .venv/bin/python -m scripts.finals_evidence --tag my-run

已有完整缓存时可严格重放：

    PYTHONPATH=src .venv/bin/python -m scripts.finals_run \
      --tag my-replay --replay-cache my-run --workers 1

重放时的 provider 和 model 与记录时保持一致。严格重放缺少任何响应即失败，不联网补答。提交包不包含模型响应缓存，需要先完成一次转换并保留响应目录。结构比较工具可通过 python -m scripts.evalsuite --help 查看参数。

## 常见问题

DTD 加载失败：检查是否在正确虚拟环境中运行，按 requirements.txt 安装 lxml 6.0 以上，勿混用其他 Python 环境。

模型调用失败：检查凭据、模型权限和服务连通性；详细原因见运行日志。

有 XML 但提示待确认：说明候选已生成而自动检查存在未解决事项，应查看原稿定位与检查摘要。

预览与 Word 视觉不一样：JATS 表达语义结构，预览采用通用期刊样式，不以复刻 Word 页码和视觉版式为目标。
