## 固定范围

1. 上传：DOCX 选择/拖放/移除/替换、格式/空文件/大小检查；DeepSeek、Qwen 同级选择；出版信息集中展示；不暴露凭据、内部模型组合或首次上传缓存决策。
2. 处理：上传、排队、转换阶段、网络重连、失败/失效；刷新后恢复当前任务；转换下一篇、重新转换不丢掉已有结果。
3. 结果：稿件预览为主体，目录导航，具体问题定位；不以印章或词级比例代替文件状态；XML、检查详情、型号与统一实际 Token 明细按需查看。
4. 原稿对照：真实 DOCX 的段落/格式/表格/图片/公式；保留上下文；准确区分局部定位和区域对照，不把输出反用作原稿；不宣称还原 Word 分页。
5. 受控编辑：出版信息（DOI、期刊及必要字段）；文章题名、作者姓名/顺序、单位与作者关联、通讯作者/通讯信息、ORCID。只修改明确操作字段，保留未改字段的混合格式、脚注及其他关系。
6. 修改闭合：明确保存/取消、未保存提醒、并发版本冲突、保存失败保留输入、原始版本可恢复；更新实际 XML、预览、相应检查及下载；不重跑模型处理人工字段修改；旧检查不冒充新版本检查。
7. 同步使用文档、技术方案相关章节/截图及提交包；保留冻结双模型实验，不把人工改稿算进自动转换成绩。

明确不做：整篇自由编辑、复杂表格/数学编辑器、多人审核/签名/权限平台、完整历史任务管理、引用目标编辑、高级 XML 编辑。本轮 XML 仍可查看和下载。不得改识别提示词、重问策略或重启转换核心架构优化；必要后端支持限定在 Web 结果编辑与任务恢复层。
