# P1 金标准结构清单与 SemanticDoc v2 完备下界

## 结论

已遍历 14 份金标准，共 31015 个元素、119 种标签、67 种“标签@属性”组合、103 处媒体引用。

SemanticDoc v2 不需要为每个 JATS 标签造一个同名类，但必须能以语义实体、SourceText、关系边、显示对象、确定性渲染骨架和 PubConfig 完整承载这些事实。下表是实现阶段的强制下界：装载器遇到表中结构却无承载位时必须报错，不得保留原始 XML 逃逸。
