# P5 全原生表属性与交付事务实验

## 覆盖范围

14 例 docx 共 41 张原生表，金标准共 38 张对应的原生表。按表文本身份一对一匹配 38 张，余下 3 张均为 X02 图形内部布局表，不是 JATS 文章表。另有 14 张从纯文本重建的金标准表，不纳入原生表物理属性实验。共对齐 2337 个金标准单元格。

## 四种闭合状态

- **colspan_rowspan → ① OOXML 直接/继承确定性取得**：gridSpan/vMerge 是 OOXML 封闭结构；38 张目标原生表的起始格数与金标准单元格数对齐（S03 的 3 个重复布局格在文本单调对齐时显式跳过）。
- **scope → ② 语义判断取得**：w:tblHeader 只覆盖少部分列头，不表达行头；必须用表内容语义判断，P5 的金标准单元格 scope 作判真夹具。
- **align_valign_border → ④ 输入不可判定，需要裁定**：属性值可从直接属性/默认值取得，但金标准是否发射这些可选 JATS 表格样式属性与 docx 信号不一致；盲目全发射会产生大量 extra。
- **width → ④ 输入不可判定，需要裁定**：S01–S05 的金标准宽度逐列等于 w:tblGrid 归一百分比，但 X01 同样存在 pct 直接宽度却统一发射等宽；03 又是第三种非等宽结果，输入不足以确定体例选择。
- **transaction → ① OOXML 直接/继承确定性取得**：并列 XML/媒体路径只能提供加锁+备份+失败回滚的可恢复事务，不能宣称单次原子替换。

## 事务保证

- 保证等级：`recoverable-not-atomic`。
- 第一个路径替换后注入异常，旧产物完整恢复：True。
- 正常替换后新 XML 与新媒体同时就位：True。

## 结论与阻断决策项

P5 完成了全量实验，但按施工图门禁，`align/valign/border` 的“是否发射”与 `width` 体例属于④。不能由施工者自行删除目标，也不能按样例号分支。建议的最小裁定是：**把表格物理属性发射策略作为显式 `PubConfig.table_style_profile`，未配置时发出 `review_blocking`，不根据样例或 DOI 暗猜。** scope 继续按语义判断实现，合并属性和可恢复交付按确定性代码实现。
