# 文档体系导览

本目录是 word2jats 项目的完整文档，既是**项目执行记录**，也是一本**学习手册**。建议按顺序阅读。

> **一句话定位**：本作品要做的是——把投稿用的 Word 论文稿，自动转成学术期刊出版通行的结构化全文 XML（**JATS** Publishing DTD v1.3，国际期刊界用来标记论文全文的标准）。核心不变量是**内容守恒**：文字本来就在 docx 里，转换只给已有文字判定正确的结构标签——绝不用模型从图片里"读"字（OCR）、绝不扩写编造。质量主体是**确定性管线**（解析+分类+构建，`--llm off` 即产出合规 XML，10 样例总缺陷 4316→397）；LLM 只做**结构判断**——管线内难例兜底（参考文献难例从原文切分，带守恒护栏）+ `--agent` 核对/修复闭环（把输入 Word 渲染成页面图作人眼真值，用本地多模态模型 **VLM**（能"看图"的语言模型）核对，修章节层级/作者归属/声明拆分/漏作者，实测在确定性基础上只好不坏）。详见 `01-设计/01-架构设计.md`。

## 🔑 三条贯穿全项目的核心结论

1. **上线版本 ≠ 由 docx 唯一算出来的结果**：委员会上线版本掺了人工编辑和外部补充的信息（C 档），不可能、也不该要求逐字节对得上；评测对照物是"结构参考"(A+B 无 C)，目标是产出**合规、完整、尽量还原原文结构**的 JATS（详见 `00-调研/02` §1、`03-评测/评测体系设计.md`）。
2. **样式名不可靠**：真实投稿的 docx 经常没有样式名或样式名乱标，判断各部分扮演什么角色主要靠分析内容本身，这样换没见过的文档也能处理。
3. **内容守恒 + 确定性优先，LLM 只判结构**：文字本就在 docx 里，任务是给已有文字判定结构标签——确定性代码只搬运原文、天然守恒，承担质量主体（R17 重构后确定性档 10 样例总缺陷 4316→397，降 90.8%，见 `02-开发/03-迭代日志.md` R17）：参考文献搜索式切分、图片表外部化为 graphic、制表符表切 Tab 还原都归确定性。死规则枚举不完的**结构歧义**（无样式子标题、作者归属、裸声明句）与参考文献难例交给 LLM，但它只输出判断、不产生文字（守恒护栏：返回字段必须是原文子串，越界即拒；实测 +LLM+agent 只好不坏）——这是评分"创新性"的落点。曾经的"VLM 看图重建表"已删除：OCR 读图必造字（样例2 实测编造 617 词）；闭环现自动修的是章节层级、作者归属、声明拆分、漏作者，**漏表、漏图、漏公式只检出并记录、不自动补**（见 `01-设计/02-智能循环架构.md`）。`--llm off` 不依赖模型即产出合规、可交付的 XML。
