# word2jats 项目文档

word2jats 面向期刊编辑，把 Word 稿件转换为 JATS 1.3 XML 与配套图片，并提供可视化校样、原稿核对和复核记录。

本文档以决赛版实现为准。理解方案先读 04，核对效果读 06，实际运行读 09。

核心思路是让模型判断结构，让程序从原稿取回正文与文献内容。文首作者、机构等元信息采用受检查约束的模型 XML 通道，是明确的例外。原文定位降低改写风险，覆盖与来源检查发现遗漏和异常，编辑核对处理自动化难以确定的部分；三者共同构成质量控制，不能把任何单项通过等同于全文绝对正确。
