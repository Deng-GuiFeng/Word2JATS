# word2jats 项目文档

word2jats 把学术论文的 Word 投稿稿（`.docx`）自动转换成 **JATS 1.3** 标准 XML——一种国际学术出版界通用的、用来描述期刊论文结构的 XML 格式。

这套文档写给一类读者：**工科出身、做事严谨，但不熟悉学术出版和 XML 排版，也不打算读源码**。它想同时办成两件事——让你完整理解这个项目、能对它把关和维护；也让你借着一个真实项目，把"学术出版结构化"这一陌生领域从零学到手。所以文档里凡是术语，第一次出现都会先讲明白。

## 一句话记住整个方案

**大模型只负责"判断结构"（这一段是标题还是正文、这条参考文献的各字段边界在哪），从不负责"生成文字"；所有正文文字都按源块编号从 Word 原文原样取回。** 这样内联格式零损失、内容也不会被模型改写或编造——本项目把"转换后正文与源稿逐字一致、不增不减不改"这条铁律叫**内容守恒**，它是**结构上就做不到改**（文字压根不流经模型），而不是靠事后比对补救。这正是本项目区别于"纯模板规则"和"纯大模型改写"两条常见路线的核心。详见 [04-系统设计](04-系统设计.md)。
