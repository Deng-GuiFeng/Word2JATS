# word2jats 项目文档

word2jats 把学术论文的 Word 投稿稿（`.docx`）自动转换成 **JATS 1.3** 标准 XML——一种国际学术出版界通用的、用来描述期刊论文结构的 XML 格式。这套文档面向不打算读源码、但希望完整理解本项目并能对其把关、维护的读者；同时，它也是读者借由一个真实项目了解"学术出版结构化"这一陌生领域的入门材料。

## 这套文档怎么读

建议按顺序读。前四篇讲清"这是什么问题、需要哪些背景、数据长什么样、我们怎么解"，后三篇讲"代码怎么组织、做得好不好、怎么用"：

| 文档 | 讲什么 | 读完你会知道 |
|---|---|---|
| [01-竞赛与任务](01-竞赛与任务.md) | 比赛背景（IMR Press 出版社举办）、任务定义、评分口径、难在哪 | 这个项目要解决的到底是什么问题，成败以什么衡量 |
| [02-领域基础](02-领域基础.md) | JATS、docx/OOXML、数学公式 OMML→MathML、参考文献著录模型等必备背景 | 看懂本项目所需的领域知识，术语从零讲起 |
| [03-数据与结构参考](03-数据与结构参考.md) | 10 个样例、评测对照物"结构参考"如何构建、输入输出长什么样 | 我们拿什么数据做、拿什么当"正确答案"、边界在哪 |

## 一句话记住整个方案

**大模型只负责"判断结构"（这一段是标题还是正文、这条参考文献的各字段边界在哪），从不负责"生成文字"；所有正文文字都按源块编号从 Word 原文原样取回。** 这样内联格式零损失、内容不会被模型改写或编造——这是本项目区别于"纯模板规则"和"纯大模型改写"两条常见路线的核心。详见 [04-系统设计](04-系统设计.md)。
