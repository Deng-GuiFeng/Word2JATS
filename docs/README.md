# 文档体系导览

本目录是 word2jats 项目的完整文档，既是**项目执行记录**，也是一本**学习手册**。建议按顺序阅读。

> **一句话定位**：本作品把投稿用的 Word 论文稿，自动转成学术期刊出版通行的结构化全文 XML（**JATS** Publishing DTD v1.3，国际期刊界用来标记论文全文的标准）。方法只有一条——**LLM 做理解、规则做保证**：哪行是标题/作者/题注、哪张"表"其实是整张图片、参考文献各字段的边界，这些"看内容才能判角色"的结构判断全交给大语言模型（LLM，Large Language Model，能读懂自然语言的大模型）；把判断落成合法 XML 的机械变换与出口校验全交给确定性规则。核心不变量是**内容守恒**：正文文字本就在 docx 里，转换时以"源块索引"把原始文字原样取回，**文字不经过模型改写**，斜体/上标/加粗零损失，守恒是**结构性成立**（文字来自 docx、不来自模型输出），而非靠事后比对补救；图片/公式/被做成图片的表格只以占位符（如 ⟦IMG#1⟧、⟦MATH#1⟧）喂给模型，模型**看不到图像字节**——从物理上杜绝"从图片里读字"（OCR，光学字符识别）造出原文没有的内容。详见 `01-设计/01-架构设计.md`。

## 🔑 三条贯穿全项目的核心结论

1. **上线版本 ≠ 由 docx 唯一算出来的结果**：委员会上线版本掺了人工编辑和外部补充的信息（C 档），不可能、也不该要求逐字节对得上；评测对照物是"结构参考"(A+B 无 C)，目标是产出**合规、完整、尽量还原原文结构**的 JATS（详见 `00-调研/02` §1、`03-评测/评测体系设计.md`）。
2. **样式名不可靠**：真实投稿的 docx 经常没有样式名或样式名乱标，判断各部分扮演什么角色主要靠分析内容本身，这样换没见过的文档也能处理。
3. **LLM 做理解、规则做保证——把旧的"规则做理解 + LLM 打补丁"倒置过来**：理解（哪行是什么角色、哪张表是图片、参考各字段边界）全归 LLM；规则只做机械变换（OMML 公式转 MathML、图片外部化、JATS 序列化、交叉引用）与出口校验，不再堆永远枚举不完的死规则。文字守恒是**结构性成立**、不靠事后补救：正文以"源块索引"引用 docx 里的原始文字、渲染时按索引原样取回，模型不改写文字；只有必须把一个源块切成多个语义单元处（作者行→逐位作者、参考行→各字段、通讯段、结构化摘要块内），模型才给**子串**，出口再校验其为 docx 原文子串。图片/公式/被做成图片的表格只喂占位符、不喂图像，**物理上杜绝 OCR 造字**（旧架构曾让模型看图重建表，样例2 实测编造出 617 个原文没有的词，已彻底删除该路径）。落地效果：全 10 例合计 **198** 个缺陷、**全部通过 DTD 校验**，低于旧规则架构基线 228，且 temperature=0、同输入确定复现（详见 `03-评测/评测体系设计.md`、`01-设计/03-决赛答辩要点.md`）。
