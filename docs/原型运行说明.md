# Word2JATS · 运行说明

将学术论文的 Word 稿件（.docx 格式）转换为 JATS 1.3 XML 和配套图片，支持网页预览、原稿对照及文章与出版信息修改。

需要 Python 3.10 及以上（建议 3.12）、网络连接，以及 DeepSeek 或阿里云百炼的 API Key；不需要 GPU。下列命令均在解压后的 `可运行原型` 目录中执行。

## 1. 安装

创建虚拟环境：

```sh
python -m venv .venv
```

激活环境：Linux/macOS 使用 `source .venv/bin/activate`；Windows 命令提示符使用 `.venv\Scripts\activate.bat`。

```sh
python -m pip install -r requirements.txt
python -m pip install . --no-deps
```

提交目录中的 `.env` 已提供测试用配置，可直接运行；Qwen 测试密钥额度为 20 元。配置仅供本项目评审试用，请勿公开传播或用于其他用途。需要使用自己的账户时，编辑 `.env` 中对应字段；`.env.example` 为不含密钥的配置模板。

| 页面选项 | 密钥字段 | 调用模型 |
|---|---|---|
| DeepSeek | DEEPSEEK_API_KEY | deepseek-flash |
| Qwen | DASHSCOPE_API_KEY | 主流程 qwen3.7-plus；文首 qwen3.8-max |

转换会消耗模型服务额度。替换密钥时须一并核对接口地址、模型权限和账户余额；密钥只在服务端读取，不传给浏览器。

## 2. 网页转换

```sh
python -m webapp
```

打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)，选择已配置的模型，上传 Word 稿件。DOI 和期刊可在上传时填写，也可转换后补充。转换完成后查看结果，按需对照原稿、修改信息，点击“保存修改”后下载。

成果包名为 `Word2JATS-稿件标识.zip`。包内以 JATS XML 和 `figures.zip` 为主体；将图片包解压到 XML 所在目录，即可取得 XML 引用的配套资源。检查摘要和用量记录一并提供；修改过的结果附修改记录。下载对应当前保存版本，不包含尚未保存的输入。

“用量”显示生成所用分析的实际模型用量；复用已有分析时仍保留原始计量，并另行说明本次新增量。手动修改信息不调用模型。“更多”中可恢复自动生成的原始版本，或创建新的转换任务。

运行期间保持终端开启，按 `Ctrl+C` 停止。需要更换端口时使用 `python -m webapp --port 8001`。上传稿件、结果和修改保存在 `webapp/_runs/`，模型回答缓存保存在 `webapp/_cache/`；重要成果请及时下载，并按需管理本地文件。

## 3. 命令行转换

将下面的路径替换为自己的 Word 文件：

```sh
python -m word2jats convert "论文.docx" --llm deepseek -o output/
```

使用 Qwen 时改为 `--llm dashscope`。可通过 `--journal JIN --doi 10.31083/JIN49347` 提供期刊与 DOI；不要填写与稿件无关的信息。完整参数见 `python -m word2jats convert --help`。

命令执行后打印结果路径。自动检查通过时，XML 与配套图片发布到 `output/`；需要处理的结果保留在其中的候选目录，并附 `report.json`。网页与命令行调用同一转换流程，网页额外提供编辑和成果打包。

## 常见问题

- 无法调用模型：核对 `.env` 中的密钥、账户余额、模型权限及网络连接；只配置了一种模型时，页面选择对应选项。
- 提示缺少出版信息：在结果页的“出版信息”中补充后保存。内容或结构问题可查看“检查详情”并对照原稿处理。
- 预览与 Word 分页不同：预览呈现 JATS 内容结构，不复刻 Word 版式。部分旧式图片无法直接显示时，可下载原文件查看。

`src/word2jats/` 包含转换代码、提示词、DTD 和公式样式表；`webapp/` 包含网页服务与预览资源。第三方资源许可随文件保留，项目许可见 [LICENSE](LICENSE)。
