## 最难自动化的点

**对本文档而言，从 docx 自动转 XML 最难自动化的点：**

1. **图片表格 → 结构化 `<table>`（最难）**：docx 内 `w:tbl` 数量=0，全部 8 张表都是**整张图片**（image1, image5-11）。金标准却把它们 OCR 成完整的 `<table>`（colgroup/thead/tbody/tr/td，含 `width` 百分比、`border`/`align`/`valign`/`style`、`scope="col"`）。这要求图像 OCR + 表格结构重建 + 单元格样式生成，几乎不可能纯规则自动化。其中 Table 2/3（image5/image6）还需识别"Illustration"列里的设备小图，**裁剪**为 15 个 `InnerTable-Graphic{n}` 并以 `<graphic position="anchor">` 嵌入对应 `<td>`。

2. **参考文献外部富化**：docx 参考文献为缩写 Vancouver 纯文本且**无 DOI**。XML 需要(a)期刊缩写→全称、(b)拆解 volume/issue/页码并丢弃 issue、(c)**逐条补全 DOI**（需 CrossRef/PubMed 联网查询）、(d)>6 作者截断 etal。这些都依赖外部数据库，非文本解析可得。

3. **大量元数据 docx 缺失、需外部供给**：DOI、收稿/修回/录用日期(history)、版权(permissions)、学术编辑(editor contrib)、Author Contributions、Funding(含基金号)、Ethics、Acknowledgment、Conflicts、Publisher's Note —— grep 验证这些在 docx 正文/页眉页脚/脚注中**均不存在**，必须从投稿系统/生产数据库注入。

4. **无样式段的层级判定**：正文主体段落几乎全无 pStyle（=Normal），二/三/四级标题、正文 p、表图 caption 都靠**文本模式**（编号正则 `2.1.1`、前缀 `Table N.`/`Fig. N.`、bullet `●`）区分，样式名无法直接利用。

5. **作者-单位-ORCID 关联**：作者行用逗号分隔 + run 级上标 `1†`/`1*`/`2`，需解析上标拆成 aff/fn/corresp 三类 xref；ORCID 在独立段落按姓名回填并补 `https://orcid.org/` 前缀；姓名按"末词=surname"拆 surname/given-names。

6. **bullet 列表语义重塑**：docx 的 "● Key Points"/"● Key Updates..." 被提升为子 sec 的 title 并重新编号（2.1.1.1/2.1.1.2），其下 bullet 项降级为普通 `<p>`（不生成 `<list>`）—— 这是语义重组而非格式直译。

## 固定模板 vs 文档特有

**IMR Press 固定模板（可硬编码/查表，不依赖 docx）**
- 整个 `journal-meta`：journal-id=RCM、journal-title/abbrev、ISSN(1530-6550/2153-8174)、publisher=IMR Press —— 由期刊代码 RCM 查表得到。
- DTD 声明与根元素属性（`dtd-version="1.3"`、`xmlns:mml`、`xmlns:xlink`）。
- `permissions` 的 CC BY 4.0 license-p 文本、copyright-statement 模板（"Copyright: © {year} The Author(s). Published by IMR Press."）。
- `fn-group` 的 Publisher's Note 整段文本。
- back 的标准小节集合与标题（Abbreviations / Author Contributions / Ethics Approval and Consent to Participate / Acknowledgment / Funding / Conflicts of Interest）及其 `<sec>`/`<ack>` 元素选择；缺省值 "Not applicable." / "The authors declare no conflicts of interest."。
- id 编码方案：sec=`S{n}[.SS.SSS.SSSS]`、p=`{secid}.p{n}`、fig=`F00{n}`/graphic=`F00{n}.g1`、table=`T00{n}`、ref=`b{n}`、aff=`aff{n}`、corresp=`cor1`、fn=`fn-1`。
