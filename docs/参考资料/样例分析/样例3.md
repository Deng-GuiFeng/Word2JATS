## 公式存在形式
公式是 **OMML**（`m:oMath` 元素），字体 `Cambria Math`。公式编号"(1)"是同一段落内一个**独立文本 run**（不在 oMath 内），需配对。例：
```xml
<m:oMath><m:r><w:rPr><w:rFonts w:ascii="Cambria Math"/><w:color w:val="EE0000"/></w:rPr><m:t>A</m:t></m:r><m:r>...<m:t>F=</m:t></m:r>...
```

## 图片嵌入
通过 `w:drawing` → `a:blip/@r:embed` 引用关系 ID，再到 `word/_rels/document.xml.rels` 解析为 `word/media/imageN.tif`。共 5 个正文 drawing，`wp:docPr/@name`="图片 1"…"图片 5"。

## 表格
原生 OOXML `w:tbl`：`w:tblGrid/w:gridCol` 定义列、`w:tr/w:tc`，合并用 `w:gridSpan`(横) / `w:vMerge`(纵 restart+continue)，单元格内换行用 `w:br`。

## 参考文献
docx 中为 **56 个单段落**（style `afb`），每条以 `[n]` 开头的纯文本（Vancouver 风格），未结构化。

## 上下标/粗斜体
run 级 `w:rPr` 标记：`w:b`(粗)、`w:i`(斜)、`w:vertAlign w:val="superscript|subscript"`。`w:color w:val="EE0000"`(红)/`00B050`(绿) 是修订/编辑色标。

### contrib-group 作者（核心难点：拆名 + 关联单位 + 关联 ORCID）

```xml
<contrib contrib-type="author">
  <contrib-id contrib-id-type="orcid" authenticated="true">https://orcid.org/0000-0003-2351-2343</contrib-id>
  <name><surname>Yang</surname><given-names>Xiaodong</given-names></name>
  <xref ref-type="aff" rid="aff1"><sup>1</sup></xref>
  <xref ref-type="fn" rid="fn-1"><sup>†</sup></xref>
</contrib>
```

## body 结构映射

### sec 嵌套与标题层级
- docx 一级标题用 style `1`(heading 1)："1. Introduction"…"5. Conclusions" → `<sec id="S1">…<title>1. Introduction</title>`
- 子节标题（"2.1. Participants"、"2.5.1. Spectral Characteristics"）是 **Normal 段落**，靠编号深度判级：`<sec id="S2.SS1">`、`<sec id="S2.SS5.SSS1">`（三级）。
- 编号写法被规范化：docx "2.1." → XML "2.1"（去尾点）；"3.1 " 等保留。
- sec id 规则：S{n}、S{n}.SS{m}、S{n}.SS{m}.SSS{k}，由层级自动生成。

### p（段落）
正文 Normal 段 → `<p id="S1.p1">`，id 用所属 sec 路径 + p 序号。例 `<p id="S2.SS1.p1">`。

### inline 格式（run rPr → 行内标签）
- `w:i` → `<italic>`；`w:b` → `<bold>`；`w:vertAlign=superscript` → `<sup>`；`subscript` → `<sub>`
- 例（Results 3.1）：docx 斜体"χ" + 上标"2" + 下标"(4)" → `<italic>χ</italic><sup>2</sup><sub>(4)</sub>`
- 文本内"<"被转义为 `&lt;`（如 "p < 0.001"）

### styled-content（保留的颜色标记）
docx 残留的红色空格 `w:color=EE0000` 被转为：
```xml
the cross-validated<styled-content style="color:#ee0000;"> </styled-content>binary classification
```
绿色同理 `style="color:#00b050;"`。

### xref 交叉引用（**docx 为纯文本，无超链接/书签关联，由生产端识别并加 xref**）
docx body 含纯文本 "Fig. 1"、"Table 1"、"[19]"、引用串 "[<bibr>]"。`w:hyperlink`=0，虽有 33 个 bookmark 但与引用无对应。XML 生成：
- 文献引用："[19]" → `[<xref ref-type="bibr" rid="b19">19</xref>]`；多引用逗号分隔各自成 xref：`[<xref rid="b1">1</xref>,<xref rid="b2">2</xref>]`
- 图引用："Fig. 1" → `Fig. <xref ref-type="fig" rid="F001">1</xref>`
- 表引用："Table 1" → `Table <xref ref-type="table" rid="T001">1</xref>`
共生成 bibr 79 / fig 8 / table 3 个 xref。

### 列表（list）
本文 body 内列举（如 "(1)…(2)…(3)"）以行内文本表达，**未使用** JATS `<list>` 元素；段落保持为单个 `<p>`。无独立列表结构需映射。

## fig 元素结构
docx：一个含 `w:drawing` 的 Normal 段（图本身，如 P35）+ 紧随的图题段（style a3/af9/afa，如 P36 "Fig. 1. Experiment design…"）。XML 合并为：
```xml
<fig id="F001" position="float">
  <label>Fig. 1.</label>
  <caption><p><bold>Experiment design and procedure. </bold>(a) Experiment days, …</p></caption>
  <graphic xlink:href="JIN49347/fig-01.jpg" id="F001.g1" />
</fig>
```
图题首句（粗体）→ `<bold>` 前导；`xlink:href` 用 `id="F00N.g1"`。`position="float"` 固定。编号 "Fig. N." 与正文 "Fig. <xref>N</xref>" 引用对应。

## 公式处理

**输入**：docx 中公式是 **OMML**（`m:oMath`），不是图片。每条公式单独成段，段内另有独立文本 run 给出编号 "(1)"…"(6)"。

**输出**：6 条全部为 **块级 `<disp-formula>`**（inline-formula = 0），用 **MathML 3**（`mml:` 命名空间），含 `<mml:semantics>` 包裹、`alttext`（线性化源）、`id="wN"`、`display="block"`。OMML → MathML 转换。

例 公式(1) Average Frequency：
```xml
<disp-formula id="E001">
  <label>(1)</label>
  <mml:math xmlns:mml="http://www.w3.org/1998/Math/MathML" id="w1"
            alttext="AF=\frac{\sum_{i}^{}{P\left(f_{i}\right)×f_{i}}}{\sum_{}^{}{P}}" display="block">
    <mml:semantics>
      <mml:mrow>
        <mml:mi>A</mml:mi><mml:mi>F</mml:mi><mml:mo>=</mml:mo>
        <mml:mfrac>
          <mml:mrow><mml:munder><mml:mo stretchy="false">∑</mml:mo><mml:mrow><mml:mi>i</mml:mi></mml:mrow></mml:munder>…</mml:mrow>
          <mml:mrow><mml:mo stretchy="false">∑</mml:mo><mml:mrow><mml:mi>P</mml:mi></mml:mrow></mml:mrow>
        </mml:mfrac>
      </mml:mrow>
    </mml:semantics>
  </mml:math>
</disp-formula>
```

OMML 结构对应（docx 源，注意 `Cambria Math` 字体 + 残留 `w:color EE0000`）：
```xml
<m:oMath>
  <m:r><w:rPr><w:rFonts w:ascii="Cambria Math"/><w:color w:val="EE0000"/></w:rPr><m:t>A</m:t></m:r>
  <m:r>…<m:t>F=</m:t></m:r>
  …（m:f 分式 → mml:mfrac，m:nary ∑ → mml:munder/msubsup，m:sSub → mml:msub）
</m:oMath>
```

编号映射：disp-formula 的 `id` 用 `E001`…`E006`，`<label>` 取段内 "(N)" 文本 run；`mml:math/@id` 用 `w1`…`w6`。`alttext` 是公式的线性 TeX-like 串（其中可见原稿瑕疵被保留，如 E004 `SE=-P\_i×log_{2}P_{i}`、E006 括号错位 `\left\{\left(P\right\}_{i}`，说明转换保真度优先、未修正原稿数学错误）。

转换映射要点：`m:f`→`mfrac`，`m:nary(∑)`→`munder`/`msubsup`，`m:sSub`→`msub`，`m:sSup`→`msup`，`m:d`(括号)→`mfenced`，`m:acc`(上划线 P̄)→`mover accent="true"`。

## 参考文献处理

- **格式：混用** —— 42 条 `<mixed-citation>` + 14 条 `<element-citation publication-type="journal">`。
  - mixed-citation：保留 docx 原始 Vancouver 文本（仅做 `&` 转义、DOI 链接保留为纯文本），未拆字段。
  - element-citation：被完整解析为子元素 `person-group/name(surname+given-names)`、`article-title`、`source`(套 `<italic>`)、`year`、`volume`、`fpage`(/`lpage`)、`ext-link`(DOI)。
  - 14 条 element 多为高影响期刊（Nature Communications/Scientific Data 等），可能是生产端按 DOI 反查 CrossRef 元数据后结构化；其余保 mixed。
- 每条均含 `<label>[N]</label>`。

真实片段：

mixed（b2）：
```xml
<ref id="b2"><label>[2]</label>
  <mixed-citation> Dawson D, Reynolds AC, Van Dongen HPA, Thomas MJW. Determining the likelihood that fatigue was present in a road accident: A theoretical review and suggested accident taxonomy. Sleep Medicine Reviews. 2018; 42: 202–210. https://doi.org/10.1016/j.smrv.2018.08.006 </mixed-citation>
</ref>
```

element（b9，含 fpage 无 lpage）：
```xml
<ref id="b9"><label>[9]</label>
  <element-citation publication-type="journal">
    <person-group person-group-type="author">
      <name><surname>Kaveh</surname><given-names>R</given-names></name>
      <name><surname>Schwendeman</surname><given-names>C</given-names></name>…
    </person-group>
    <article-title>Wireless ear EEG to monitor drowsiness</article-title>
    <source><italic>Nature Communications</italic></source>
    <year>2024</year><volume>15</volume><fpage>6520</fpage>
    <ext-link ext-link-type="uri" xlink:href="https://doi.org/10.1038/s41467-024-48682-7"> https://doi.org/10.1038/s41467-024-48682-7</ext-link>
  </element-citation>
</ref>
```

element（b3，含 lpage）：person-group 4 作者 + `<fpage>272</fpage><lpage>289</lpage>`。

注意：docx 多作者用 "et al." 的条目（如 b1、b7），在 element 化时会还原作者列表或保 mixed；多数 et al. 条目恰好保留为 mixed。

## 对本文档最难自动化的点

1. **style 名无语义、且被错用（最大坑）**：body 正文与各级标题几乎全是无 pStyle 的 Normal；styleId 是混淆名（afa/afb/afe/aff1/aff9…），必须读 `styles.xml` 的中文 `w:name` 才知角色；更糟的是 `afa`(表注) 被错套到多个正文段（P81–89）。**纯靠 style 必错，必须结合文本特征（编号前缀、是否短行、上下文位置）做语义判定。**

2. **作者—单位—ORCID 三向关联**：作者一行（affb）中 superscript 数字/符号要解析成 aff/fn/corresp 的 rid；姓名要从 "given surname" 翻转为 surname/given-names；ORCID 在另一独立纯文本块（P10–17）须按姓名回填到对应 contrib。

3. **交叉引用全靠文本识别**：docx 里 "Fig. 1"/"Table 1"/"[19]" 都是**纯文本，无超链接、无书签关联**（hyperlink=0，bookmark 33 个但不匹配），必须用正则/NLP 识别并生成 79+ 个 `<xref>` 且正确指向 F00N/T00N/bN。

4. **图片三方命名对齐**：docx media（imageN.tif）↔ figures.zip（fig-0N.jpg）↔ XML href（JIN49347/fig-0N.jpg）**无共同文件名 token**，只能靠正文出现顺序对齐；还须排除页眉 logo（image6/image7）。

5. **OMML→MathML 转换**：6 条公式需 OMML→MathML3 转换，且公式编号"(N)"是同段独立 run 须配对；原稿数学瑕疵（括号错位）需保真不"修正"。

6. **参考文献 mixed/element 混用判定**：56 条中哪些做完整字段解析、哪些保原文，缺乏明确规则（疑似按能否 DOI 反查元数据决定），自动化难以稳定复现这一比例。

7. **生产补全/改写的内容**：DOI、ISSN、copyright/license、accepted 日期（docx 为占位"待接收"）、affiliation 邮编前置改写、author-contributions 全名→缩写（另含角色扩充+样板句追加）、摘要单段拆 4 sec——这些是 docx 中缺失或不同的，需外部数据或规则补齐。

## 固定模板（可硬编码/查表） vs 文档特有（必须从 docx 提取）

### IMR 固定模板（可硬编码 / 按 journal-id 查表）
- DOCTYPE/JATS v1.3 声明、根 `<article>` 命名空间与属性
- journal-meta 全部：journal-id `JIN`、journal-title、abbrev-journal-title、ISSN（ppub 0219-6352 / epub 1757-448X）、publisher-name `IMR Press`
- permissions 模板：copyright-statement 句式、CC BY 4.0 license-p（仅年份随出版年变）
- article-categories 取值集合（Original Research 等）、ref-list `<title>References</title>`
- 结构常量：fig/table-wrap `position="float"`、graphic id 后缀 `.gN`、href 前缀 = DOI 文章号（`JIN`+数字）、sec id 命名法（S/SS/SSS）、fn/corresp/aff 的 id 前缀（fn-N/cor1/affN）
- contrib-id 写法 `https://orcid.org/…` + `authenticated="true"`、editor 的 `<role>Academic Editor</role>`

### 文档特有（必须从 docx 提取/推导）
- 标题、全部作者姓名与顺序、各作者的 aff/equal-contrib/corresp 归属、ORCID、通讯邮箱
- 三条单位全文、学术编辑姓名
- 摘要四段内容、关键词列表
- 正文全部 sec/title/p、行内格式、styled-content 颜色标记
- 5 张图（顺序→文件名）、图题；3 张表（含 gridSpan/vMerge/break、列宽）、表题、表注
- 6 条公式 OMML→MathML + 编号
- 56 条参考文献文本（及 element 化解析）
- back 各 sec（数据可得性/作者贡献/伦理/致谢/资助/利益冲突/AI 声明）

### 需外部补齐（docx 既无、模板也定不死）
- DOI / publisher-id（生产分配）
- history 三日期（docx 的 accepted 为占位"待接收"，须从投稿系统取）
- 出版年/copyright-year（随发表时间）
- affiliation 邮编前置改写、author-contributions 全名→缩写规则（另含角色扩充+样板句追加，编辑规范）
