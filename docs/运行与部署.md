# 运行与部署

安装和基础操作见根目录 [README](../README.md)。

## 配置和持久化目录

Qwen 使用 `DASHSCOPE_API_KEY`，DeepSeek 使用 `DEEPSEEK_API_KEY`；接口地址可通过对应的 `*_BASE_URL` 配置。凭据由环境变量或本地 `.env` 提供，不应加入源码、日志或镜像。

| 环境变量 | 默认目录 | 内容 |
|---|---|---|
| `W2J_WEBAPP_CACHE` | `runtime/cache/` | 大模型响应与原始用量 |
| `W2J_RUNS_DIR` | `runtime/tasks/` | 原 Word、自动输出、人工修改及任务快照 |
| `W2J_UPLOADS_DIR` | `runtime/uploads/` | 上传分片暂存 |

默认路径相对项目目录计算，不依赖启动命令所在目录。命令行转换默认输出到当前目录的 `output/`，与网页任务分开。

任务快照保存绝对路径。不要直接移动已有任务目录后启动服务；迁移时须同步更新快照及相关 JSON 中的路径，并验证原链接、下载和修改版本。删除任务会使对应链接不可用，重要成果应先下载。

## 当前部署

本机服务名为 `word2jats-web.service`，运行根目录的 `.venv/bin/python -m webapp`，监听 8504 端口。公网入口为 https://word2jats.jianglab.work。

```bash
systemctl status word2jats-web.service
journalctl -u word2jats-web.service -n 50 --no-pager
```

维护服务配置需要管理员权限。修改 Python 代码后需重启服务；重启前先确认没有正在转换的任务。前端资源直接由部署目录提供，应在临时端口验证后再发布。

服务使用进程内任务表和线程池，须以单个服务进程运行，不支持直接增加多个 Uvicorn worker。

## 临时验证

用独立任务目录启动，避免试验污染已有任务：

```bash
W2J_RUNS_DIR=/path/to/check/tasks \
W2J_UPLOADS_DIR=/path/to/check/uploads \
W2J_WEBAPP_CACHE=/path/to/check/cache \
.venv/bin/python -m webapp --port 1864
```

检查上传、状态更新、预览、原稿、图片、字段保存、恢复和下载；验证用量在缓存复用后仍正确展示。不能仅以首页返回 200 判断转换可用。

## 容器

```bash
docker build -t word2jats .
docker run --rm -p 8000:8000 --env-file .env \
  -v /path/to/runtime:/app/runtime word2jats
```

容器本地没有缓存时，新转换需要有效大模型凭据。EMF 图片预览需要 LibreOffice，WMF 预览使用系统 GdkPixbuf 解码器；容器默认不安装这些可选工具，相关格式的原始媒体仍会随成果交付。

## 访问和留存

原型没有账号或权限系统，公开部署应在入口处限制访问和用量。稿件、人工修改和请求缓存可能含未发表内容，不能作为公开静态资源或源码发布。失效分片与已确认不再需要的任务可以删除；不要将缓存与真实稿件混为一类。
