# X01–X04 结构参考构建流程（可复现留痕）

这里是为四份外部投稿 X01–X04 建 `结构参考.xml` 的全套工具与中间产物，供审计复核。
10 例（01–05、S01–S05）的参考不由本流程产出，其历史工具见 [`../refxml.workflow.js`](../refxml.workflow.js)（已退役）。

## 设计要点：判断独立，取字机械

参考结构是「假设转换器 100% 准确、从这份 docx 转出来的 JATS」。它是评测的标尺，
所以构建过程必须与转换器的判断相互独立（否则拿转换器的输出评转换器），
同时必须杜绝模型在誊抄时改字。

做法是把两件事拆开：

- **判断**由模型做，但它只回答「哪个块 idx 归哪个 JATS 元素」，**一个正文字符都不许打**；
- **取字**由脚本做，按 idx 从 docx 原文取回，包括 run 级的上标/下标/斜体。

决策单里允许出现的短字段（姓名、日期、邮箱、参考文献各字段）一律做**子串校验**：
不是对应源块原文的连续片段就报错。编造在结构上不可能发生。

## 文件

| 文件 | 作用 |
|---|---|
| `blocks.py` | docx → 块清单。每块 idx + 逐字文本 + run 级格式 + 媒体/OMML/OLE 位置。确定性，无判断 |
| `view.py` | 块清单 → 判定用的可读视图（每行一块） |
| `X0N.decisions.json` | 判定产物：idx → JATS 元素的映射。**不含正文文字** |
| `refs.py` | 参考文献著录的确定性拆分（APA / 温哥华两种人名写法），拆不动的不硬拆 |
| `refs_unparsed.json` | 规则拆不动的 17 条原文 |
| `refs_manual.json` | 那 17 条的逐条拆分结果（体例特殊：书籍章节、学位论文等） |
| `assemble.py` | 按决策单取字装配 XML + 四道出口校验 |
| `build.py` | 主程序 |

## 复现

```bash
PYTHONPATH=scripts/eval/refbuild .venv/bin/python scripts/eval/refbuild/blocks.py X01 X02 X03 X04
PYTHONPATH=scripts/eval/refbuild .venv/bin/python scripts/eval/refbuild/build.py X01 X02 X03 X04
```

产物落在 `tmp/refbuild/out/<key>/`（XML + 外部化图片）。决策单已冻结在本目录，
所以除判定环节外全流程确定性可复现；重跑不会调用模型。

## 四道出口校验（全部必须通过）

1. **DTD**：JATS Journal Publishing 1.3，用项目内置 DTD 离线校验。
2. **块覆盖闭合**：docx 每个顶层块要么进了 XML，要么列入 `dropped` 并写明理由，不允许无交代的块。
   这道是防漏抄的关键——[`../fidelity.py`](../fidelity.py) 的 L1 主口径拿结构参考当「应保留内容」的仲裁，
   参考漏抄会把转换器同样的漏抄一并豁免掉，缺陷就此静默。
3. **图片**：每个 `<graphic xlink:href>` 指向的文件存在、可解码为真图、
   **字节 md5 与 docx 内嵌媒体逐字节相同**（原字节外部化、不重编码的硬证据）。
4. **子串校验**：决策单与参考文献拆分里的每个字段值，都必须是对应源块原文的连续片段。

## 本批四例的口径决策

逐例的完整记录在各自 `样例数据/X0N/scope.json` 的「构建口径」字段。共通的三条：

- **投稿件不产出 `article-id`**。DOI 是文章被接收后才分配的，投稿那一刻不存在；
  转换器同样拿不到，参考里补了就是凭空给转换器造一个必然失分项，且属 C 档编辑加工。
- **docx 无编号的参考文献不产出 `<label>`**（X01 除外，其原文自带 `[n]`）。
- **整块统一的字体格式属 Word 版式**（整行标题加粗、整行关键词斜体），不产出 `<bold>`/`<italic>`；
  只有块内存在差异的才是语义（作者角标、化学式下标、局部斜体），逐一保留。
  依据是 JATS 对 `<italic>` 的定义——「与周围文本不同的排版强调」，整块统一者无「周围」可言。

## 尚未做的（审计须知）

- **判断层没有冗余**：每份 docx 只有一次结构判定，没有第二方独立判定后比对分歧，
  也没有逐疑点的多方辩论。10 例当年的流程有这一环（见 `样例数据/说明.md` 第 7 条），本批没有。
- **参考文献字段边界未经独立复核**：子串校验能防编造，防不了切错边界
  （把篇名末尾切进刊名，两边都还是原文子串，校验照样通过）。
- X02 的 (8) 号公式，其图为浮动锚定对象、锚在前一段，本块只剩编号文本，未产出公式元素。
