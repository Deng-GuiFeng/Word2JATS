## 二、实现覆盖映射

| 被评对象 | 实现入口 | 比较或检查方式 | 失败表现 |
|---|---|---|---|
| 候选包边界 | `artifacts.CandidatePackage` | 唯一顶层 XML、引用闭包、未引用文件 | package 问题 |
| XML 良构与安全 | `artifacts.parse_xml`、`validity.validate_xml` | 禁网络、禁实体展开、禁内部子集 | validity / coverage 问题 |
| JATS 结构 | `validity.validate_xml` | 本地 JATS 1.3 MathML3 DTD | `DTD_INVALID` |
| 元素与层级 | `canonical.canonicalize`、`compare.compare_nodes` | 通用有序树逐项比较 | 各领域 `ELEMENT_*` |
| 全部属性 | 同上 | 展开命名空间后逐属性比较 | `ATTRIBUTE_CHANGED` |
| 直接文本与尾文本 | 同上 | 除显式排版空白外逐字符比较 | `TEXT_CHANGED`、`TAIL_TEXT_CHANGED` |
| 重复对象 | `compare._pair_children` | 键到有序索引列表，逐次消耗 | 不会塌缩；缺失/多出逐项报告 |
| 子元素顺序 | 同上 | 精确身份候选索引及相邻边 | `CHILD_ORDER_CHANGED` |
| ID 与 rid | `canonical._id_anchors` | ID 改为语义锚点，rid 改为目标锚点 | `TARGET_CHANGED`、闭包问题 |
| 媒体字节 | `artifacts`、`canonical` | 严格解码、SHA-256 代替 href 比较 | `MEDIA_*` |
| 媒体来源 | `provenance.read_docx_media` | 与 `word/media/` SHA-256 闭合 | `MEDIA_NOT_FROM_DOCX` |
| docx 文字旁证 | `provenance.read_docx_text` | 段内 run 拼合后分词计数 | 报告 novel/excess/missing，不豁免金标准差异 |
| 新元素、新属性 | `canonical.canonicalize` | 默认进入通用树；领域表仅影响归类 | strict fallback 与普通差异问题 |
| 完整性证明 | `CoverageReport` | 所有输入对象计数，非注释特殊节点列为 unhandled | `COVERAGE_INCOMPLETE` |
| 复现 | `engine._evaluator_hashes` | 输入和评测器清单 SHA-256 | 报告可核对 |

## 三、交付验收命令

为确保测试运行产生的临时文件也留在 V2 目录内，可从项目根目录执行：

```bash
PYTHONDONTWRITEBYTECODE=1 python -m pytest -q scripts/eval_v2/tests \
  --basetemp=scripts/eval_v2/.pytest-tmp \
  -o cache_dir=scripts/eval_v2/.pytest_cache
```

命令行冒烟检查：

```bash
python -m scripts.eval_v2 --help
python -m scripts.eval_v2 evaluate --help
python -m scripts.eval_v2 batch --help
```

测试通过后，`.pytest-tmp`、`.pytest_cache`、`.scratch` 和 `__pycache__` 都只是本地运行产物，不属于交付源码。
