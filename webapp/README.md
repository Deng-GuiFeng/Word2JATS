# word2jats 校样工作台

上传 Word，得到 JATS XML、原始图片与可核对的校样。需要 Python 3.10+ 和模型 API 凭据。

在项目根目录安装 requirements.txt，在本地 .env 配置 DASHSCOPE_API_KEY，然后运行：

    python -m webapp

浏览器访问 http://127.0.0.1:8000。转换后可查看成品、原稿差异、内容清单、合规检查和 XML；逐项记录复核结论，随文件包导出。

“重新识别全文”使用任务独立缓存。默认允许复用已有回答，结果页区分全新调用和已有分析复用。耗时见 [实测说明](../docs/06-评测与成绩.md)，不将缓存重放时间当作全新转换时间。

人工记录不会修改 XML，也不会覆盖自动检查结论。需要修订时修改 Word 原稿并重新上传。当前是单机原型，任务索引重启后失效，重要结果请及时下载。

完整设计见 [Web 应用](../docs/08-Web应用.md)，安装见 [安装与使用](../docs/09-安装与使用.md)，部署与数据管理见 [部署上线](../docs/10-部署上线.md)。
