word2jats

把 Word 稿件转成可直接交付的 JATS XML，图片、公式、表格、参考文献一并转好。JATS 是学术期刊通用的出版用 XML 格式。

第 1 步 · 上传稿件

稿件里的图片、公式、表格都会自动从 Word 里提取，无需另外上传。下面两项用来补全 Word 里没有的出版信息，可留空。

文章的数字对象标识符，投稿阶段通常还没有。填了会写入文章编号，并据此自动识别期刊。
决定输出里的刊名、ISSN、出版方等信息。留空则按 DOI 推断；都没有就标为待定。
第 2 步 · 转换中
0.0s
—
  1. 读取 Word 稿件
  2. 识别文章结构（作者、图表、公式、参考文献）
  3. 生成 JATS XML、放回图片
  4. 检查合规、核对原文

首次转换需要识别文章结构，约几十秒；同一份稿件再传会直接返回。
