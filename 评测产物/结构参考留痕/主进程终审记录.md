# 01–05 结构参考.xml 生成 · 主进程终审记录

本文件记录委员会主样例 01–05 的 `结构参考.xml`(忠实结构化 docx 的评测对照物,A+B、无 C)
的生成与终审全过程,每步可审计。参考构建方法与 A/B/C 边界见 `../../docs/03-评测/评测体系设计.md`。

## 1. 方法(多代理生成 + 主进程终审)

| 环节 | 执行者 | 产物 |
|---|---|---|
| 生成 | 每样例 **3 个独立 opus subagent**(共 15),各自从 docx 逐字构建结构参考;上线版本仅作 house-style/抽全/B 旁证 | `SXX/gen_1/2/3.xml` |
| 审核 | 每样例 **1 个 opus subagent**(共 5),逐区交叉核对 3 版、回源裁定、定稿 | `SXX/定稿候选.xml` + 审核报告 |
| 终审 | **主进程**(独立于上述 subagent),对 5 份定稿逐项独立复查、回源 docx/上线版钉死、跑独立校验 | 本文件 + 提升为 `样例数据/*/结构参考.xml` |

生成/审核工作流脚本:`refstruct-01-05`(见会话工作流留痕)。
主进程独立校验工具:`scratchpad/verify_refstruct.py`(DTD / 元数据 / 计数对账 / 图片 md5 /
docx↔参考 词多重集双向反查 / 参考文献全结构化 / 标题与 back 逐项)。

## 2. 主进程终审:逐样例裁定(全部通过,附关键"忠实 vs C 档"判定)

所有 5 篇:DTD 合法(JATS v1.3)、journal-meta/article-type/subject/ISSN 正确、参考文献 100%
`element-citation` 全结构化(mixed=0)、悬空 xref=0。词多重集"候选有·docx无"经逐项核验均为
**分词假差**(结构化剥离句点如 `interv.`→`interv`、上下标切分如 `Ca²⁺`/`1.73m²`、italic 化 `p`-value)
或 **B 档模板**(journal-meta 值、ORCID URL、permissions/Publisher's Note);无编造、无 C 误入。

- **01(RCM)**:标题用 docx 原形(非 Title Case);**录用日期用 docx 值 `16/1/2025`**(docx 年份笔误,
  忠实保留,上线版改对 2026 属 C);正文/摘要用 docx 原文(上线版数十处 copyedit 属 C);**表 4 张按 docx
  放置于正文**(上线版移 1 张入附录属 C 重排);back 仅建 docx 实有 4 节(Funding/Conflict of interest/
  Author contributions/Ethics Approval),不加上线版新增的 Availability/Acknowledgment/Supplementary(C);
  参考文献 39 条 element,字段逐字 docx(不采上线版 copyedit 串)。
- **02(RCM)**:**article-id 用干净值 `10.31083/RCM46175`**(上线版误带 `zr-sly` 后缀,同文件图片目录却用

  (T1/4–8 真表 + T2/3 以 15 张 InnerTable-Graphic 行图承载),引用委员会 figures.zip 真实图名 —— 详见 §3。

## 3. 主进程发现并修复的缺陷:02 表格

- **缺陷**:审核定稿把 docx 02 的 8 张图片表塌缩成 8 个自造文件名 `tbl-01..08.jpeg`(委员会 figures.zip
  里根本不存在这些名,真实为 `InnerTable-Graphic1..15` + `fig-01..04`),文件名校验 ✗。
- **修复(确定性嫁接)**:因 figures.zip 未提供 T1/4–8 的独立图片(上线版已将其做成真表),02 无法"全表保留为图";
  遂将候选的 8 个 table-wrap 整体替换为上线版同 id(T001–T008)的 table-wrap(T1/4–8 真表 + T2/3 含
  InnerTable-Graphic 行图)。id 完全对齐,正文表引用 rid(T001–T008)保持闭合。
- **修复后校验**:DTD VALID、悬空 xref=0、19 张 graphic(4 fig + 15 InnerTable)全部在 figures.zip 内。
  修复后"候选有·docx无"新增 valve/leaflet/regurgitation/mitral/annular 等词,系图片表内容
  (docx 中为图、文本流没有),经上线版权威转写核实,非编造 —— 属图片表的预期,已知并接受。
